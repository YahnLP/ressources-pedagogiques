# Électronique – Bac Pro CIEL (E2)

Cours, TP et ressources du module **E2** du Bac Pro CIEL (Seconde, Première, Terminale). Auteur : Yahn LE PRETTRE, Enseignant à la MFR de Pontonx – licence CC BY-NC-SA 4.0.

📖 **Site (GitHub Pages) :** <https://yahnlp.github.io/ressources-pedagogiques/>

## Contenu

| Dossier | Contenu |
|---|---|
| [`docs/seconde`](docs/seconde/README.md) | 18 séances : composants, loi d'Ohm, schémas, soudure, Arduino, capteurs, projet A1 |
| [`docs/premiere`](docs/premiere/README.md) | 19 séances : KiCad, PCB, ESP32, MQTT, Node-RED, cloud, fiabilité, CEM, projet A2 |
| [`docs/terminale`](docs/terminale/README.md) | 17 séances : mesures et PV, alimentation, validation, métrologie, préparation E2 |
| [`docs/ressources`](docs/ressources/electrolab.md) | Mode d'emploi du simulateur ElectroLab |
| [`docs/annexes`](docs/annexes/rappels-e2/README.md) | Sept packs de rappels de cours E2 (anciennes fiches, illustrées) |
| [`outils`](outils/) | Scripts : illustrations, import des fiches, génération des fichiers ElectroLab |

Seuls les **cours, TP et annexes élèves** sont publiés. Les fiches enseignant et les corrigés restent hors du dépôt.

## Travailler en local

```bash
pip install -r requirements.txt
mkdocs serve        # http://127.0.0.1:8000
mkdocs build --strict
```
