# 🖥️ Utiliser ElectroLab

> [!NOTE] 🧪 Voir aussi : [tous les Labs](labs.md) · [🔬 OscilloLab](oscillolab.md) pour apprendre à régler les oscilloscopes.

**ElectroLab** est un simulateur de circuits électroniques qui fonctionne **hors ligne** dans un navigateur (un seul fichier HTML).

▶️ **Ouvrir le simulateur : [ElectroLab — Simulateur de circuits électroniques · Bac Pro CIEL](https://yahnlp.github.io/ElectroLab/)**

📥 Pour travailler hors ligne, le fichier unique `dist/electrolab.html` est disponible dans le [dépôt ElectroLab](https://github.com/YahnLP/ElectroLab).

## Ouvrir un exercice ou un TP

1. Télécharge le fichier `.json` indiqué dans la page *🖥️ Simulateur ElectroLab* de la séance (clic droit → *Enregistrer le lien sous*).
2. Dans [ElectroLab](https://yahnlp.github.io/ElectroLab/), clique sur **Ouvrir** et choisis le fichier.
3. Le schéma s'affiche, avec ses instruments : alimentation, multimètre, oscilloscope, générateur…
4. Réponds aux questions de la page du site sur ta feuille ou dans ton portfolio.

> [!TIP]
> ElectroLab propose aussi des **TP avec correction automatique** : menu **TP ▾**. Les pages du site indiquent le TP correspondant.

## Utiliser le simulateur

| Je veux… | Je fais… |
|---|---|
| Ouvrir un instrument | **Double-clic** sur l'instrument |
| Mesurer une tension | Multimètre en **V⎓**, **en parallèle** du composant |
| Mesurer un courant | Multimètre en **mA** ou **A**, **en série** (on ouvre le circuit) |
| Mesurer une résistance | Multimètre en **Ω**, **alimentation coupée** |
| Enregistrer mon travail | Bouton **Enregistrer** : un fichier `.json` est créé |
| Reprendre plus tard | Bouton **Ouvrir** |

> [!WARNING]
> Un composant mal branché peut être **détruit** dans le simulateur (LED sans résistance, courant trop fort…). C'est volontaire : on apprend aussi de ses erreurs.
