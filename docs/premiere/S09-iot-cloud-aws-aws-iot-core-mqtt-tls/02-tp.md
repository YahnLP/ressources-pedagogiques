### 1.4 — Créer et attacher une Policy

```
→ "Créer une policy"
→ Nom : iot-ciel-lab-policy
→ Éditeur JSON → Coller :

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [

        "iot:Publish",
        "iot:Subscribe",
```

## 🧪 PARTIE 4 — Règle IoT vers CloudWatch (25 min)

### 4.1 — Créer la règle

```
IoT Core → Règles de message → Créer une règle
→ Nom : ciel_temperature_rule_[votrenom]
→ Instruction SQL :
    SELECT temp, hum, timestamp() as ts
    FROM 'esp32/[votrenom]/data'
→ Suivant
```

### 4.2 — Configurer l'action CloudWatch

```
→ Ajouter une action → CloudWatch → Envoyer des données de métriques CloudWatch
→ Espace de noms de la métrique : IoT/CIEL
→ Nom de la métrique : Temperature
→ Valeur de la métrique : ${temp}
→ Unité de la métrique : None
→ Nom de la dimension : Device
→ Valeur de la dimension : ${device}   (si votre JSON contient "device")
→ IAM Role : Créer un nouveau rôle → Créer automatiquement
→ Suivant → Créer la règle
```
