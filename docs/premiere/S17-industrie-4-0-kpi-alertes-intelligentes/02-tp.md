## 🟡 NIVEAU 2 — Alerte avec hystérésis (25 min)

**2.1** — Implémente l'alerte température avec hystérésis.
Crée le nœud function "Alerte Hyst Temp" avec ce code :

```javascript
var temp      = msg.payload;
var seuilHaut = 30.0;   // ← Modifier selon votre contexte
var seuilBas  = 28.0;

var alerteActive = context.get("alerteActive") || false;
var ancien = alerteActive;

if (!alerteActive && temp >= seuilHaut) {
    alerteActive = true;
} else if (alerteActive && temp <= seuilBas) {
    alerteActive = false;
}

context.set("alerteActive", alerteActive);

// N'envoyer un message que si l'état change
if (alerteActive !== ancien) {
    msg.payload = {
        etat   : alerteActive ? "ALERTE 🔴" : "OK 🟢",
        valeur : temp.toFixed(1),
        heure  : new Date().toLocaleTimeString("fr-FR")
    };
    return msg;
}
return null;
```

**4.3** — Dérivée (taux de variation) :

```javascript
// Détection d'une montée rapide de T°
from(bucket: "iot_salle")
  |> range(start: -15m)
  |> filter(fn: (r) => r._measurement == "sonde_climasens")
  |> filter(fn: (r) => r._field == "temperature")
  |> derivative(unit: 1m, nonNegative: false)

// Dans function "Alerte dérivée" :
var derive = msg.payload.length > 0 ? msg.payload[msg.payload.length-1]._value : 0;
if (Math.abs(derive) > 2.0) {
    msg.payload = "⚡ Variation rapide : " + derive.toFixed(2) + "°C/min";
    return msg;
}
return null;
```
