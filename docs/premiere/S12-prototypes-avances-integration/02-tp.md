```
Nouveau projet FreeCAD :
  1. Atelier Part Design

  3. Pad (extrusion) → hauteur du fond (3 mm)

  6. Sketch sur la paroi concernée → Cercle ou Rectangle
  7. Pocket (traversant) → ouverture
```
