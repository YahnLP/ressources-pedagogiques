## 🗺️ Circuit cible : Timer NE555 Astable

```
Le NE555 en mode astable génère un signal carré dont la fréquence dépend de R1, R2 et C1.

Schéma simplifié :
  +9V → IC1 (NE555 pin 8, 4) + R1 → pin7 → R2 → pin6/pin2 ←→ C1 → GND
                               pin3 = sortie signal → R3 → D1 LED → GND

Composants :
  IC1  : NE555  (DIP-8 THT)
  R1   : 10kΩ   (SMD 0805, face avant F.Cu)
  R2   : 47kΩ   (SMD 0805, face avant F.Cu)
  C1   : 100µF 16V (électrolytique THT, polarisé)
  C2   : 100nF    (SMD 0402, découplage, face avant)
  R3   : 470Ω    (THT axiale)
  D1   : LED rouge (THT 5mm)
  J1   : Connecteur 3 pins (VCC, GND, Sortie)
```

## 🟠 NIVEAU 3 — Placement mixte THT/SMD (25 min)

> **Stratégie** : les composants SMD (R1, R2, C2) vont sur F.Cu · les composants THT et le CI sur F.Cu aussi · J1 sur le bord de carte.

**3.1** — Place les composants avec cette logique :

```
BORD GAUCHE :
  J1 (connecteur) → bord gauche, accessible

CENTRE-GAUCHE :
  IC1 (NE555 DIP-8) → composant dominant, placer en premier

AUTOUR DU IC1 :
  R1 (SMD 0805) → proche pin 7 du NE555
  R2 (SMD 0805) → proche pin 6/7
  C2 (SMD 0402) → très proche pins 8 et 1 (découplage)

BAS-CENTRE :
  C1 (électrolytique THT) → séparer des SMD (imposant)

DROITE :
  R3 + D1 → section sortie, proche de l'espace libre
```

**3.2** — Pour C2 (composant de découplage), le positionner **très près** des pins 8(VCC) et 1(GND) du NE555. Pourquoi ?

```
Un condensateur de découplage doit être _____________ de la broche d'alimentation du CI
Plus il est loin → plus la piste d'alimentation a de l'inductance parasite
→ résultat : _____________ (bruits haute fréquence) sur l'alimentation du CI
```

**3.3** — Vérifie l'absence de courtyard overlap (DRC préliminaire).

```

☐ Tous les composants à l'intérieur du contour 70×55mm
```
