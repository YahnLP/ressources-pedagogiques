## 🟡 NIVEAU 2 — Simuler des données et créer le Dashboard (25 min)

### Créer un simulateur de capteur

**2.1** — Crée un flow "Simulateur Température" :

```
[inject "toutes les 2s"] → [function "Simuler données"] → [debug]
```

Configurer le nœud **inject** :
```
msg.payload  : vide (pas important)
Repeat       : interval → every 2 → seconds
```

Configurer le nœud **function** "Simuler données" :
```javascript
// Générer une température aléatoire réaliste
msg.payload = {
    temperature: parseFloat((20 + Math.random() * 10).toFixed(1)),
    humidite: parseFloat((50 + Math.random() * 30).toFixed(0)),
    co2: parseFloat((400 + Math.random() * 600).toFixed(0))
};
msg.topic = "simulateur";
return msg;
```

Deploy → Observer les messages dans debug toutes les 2 secondes.

```
Exemple de msg.payload reçu : _______________________________________________
```

## 🔴 NIVEAU 5 — Connexion InfluxDB (25 min)

### Configurer la connexion InfluxDB

**5.1** — Dans Node-RED, ajoute un nœud **influxdb out** :

```
Double-clic → Add new influxdb server :
  Version : 2.0
  URL     : http://localhost:8086
  Token   : [copier depuis InfluxDB UI → Data → API Tokens]
  Org     : CIEL

Measurement : sonde_salle_e2
```

**5.2** — Crée un nœud **function** "Formater pour InfluxDB" branché avant influxdb-out :

```javascript
// InfluxDB attend un tableau de points
var data = msg.payload;  // {temperature, humidite, co2}

msg.payload = [
    {
        measurement: "sonde_salle_e2",
        tags: {
            location: "salle_e2",
            capteur: "simulateur"
        },
        fields: {
            temperature: data.temperature,
            humidite:    data.humidite,
            co2:         data.co2
        }
    }
];
return msg;
```

**5.3** — Connecte : simulateur → [Formater InfluxDB] → [influxdb out]

Deploy → Observer le debug. Après 10 secondes :

```
Des erreurs dans le debug InfluxDB ? ☐ Non (OK) ☐ Oui → ___________________
Aller dans InfluxDB UI → Explore → Vérifier les données reçues :
Bucket : iot_salle · Measurement : sonde_salle_e2 visible ? ☐ Oui ☐ Non
```

### Lire l'historique depuis InfluxDB

**5.4** — Crée un flow de lecture :

```
[inject "Toutes les 30s"] → [influxdb in] → [function "Formater chart"] → [chart "Historique DB"]
```

Configurer le nœud **influxdb in** :
```javascript
// Dans le champ "Query" du nœud influxdb in :
from(bucket: "iot_salle")
  |> range(start: -15m)
  |> filter(fn: (r) => r._measurement == "sonde_salle_e2")
  |> filter(fn: (r) => r._field == "temperature")
  |> aggregateWindow(every: 30s, fn: mean, createEmpty: false)
```

**5.5** — Configurer le nœud **function** "Formater chart" :

```javascript
// InfluxDB renvoie un tableau [{_time, _value, ...}, ...]
// Chart Node-RED attend [{x: timestamp, y: valeur}, ...]
var points = msg.payload.map(function(p) {
    return {
        x: new Date(p._time).getTime(),  // timestamp en ms
        y: p._value
    };
});
msg.payload = [{ series: ["Température DB"], data: [points], labels: [""] }];
return msg;
```

```

Nombre de points affichés : _______
Les valeurs correspondent aux données simulées ? ☐ Oui ☐ Non
```
