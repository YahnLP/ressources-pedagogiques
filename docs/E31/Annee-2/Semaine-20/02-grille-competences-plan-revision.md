## 💡 PARTIE 5 — Après E31 : la certification CCNA

### Pourquoi passer le CCNA ?

```
✓ Reconnaissance internationale (standard industriel Cisco)
✓ Différenciateur sur le CV pour un poste junior
✓ Prérequis pour CCNP (niveau supérieur)
✓ Salaire +15-20% en moyenne pour les profils certifiés (données 2024)
```

### Roadmap vers la certification

```
ÉTAPE 1 — Préparer l'examen (2-4 mois)
  → Cisco NetAcad CCNA v7 (cours gratuit en ligne)
  → Jeremy's IT Lab (YouTube, 200+ heures de contenu)
  → Labs PT quotidiens (30 min/jour)

ÉTAPE 2 — Planifier l'examen
  → Examen : Pearson VUE en centre agréé
  → Coût : ~330€ (vérifier les tarifs actuels)
  → Durée : 120 min · 825/1000 pour valider
  → Validité : 3 ans (recertification requise)

ÉTAPE 3 — Maintenir la certification
  → Recertifier avant expiration via un examen supérieur OU
  → Accumulation de crédits de formation Cisco

CENTRES D'EXAMEN PEARSON VUE (rechercher sur pearsonvue.com) :
  → Chercher "Cisco CCNA 200-301 près de [ta ville]"
```
