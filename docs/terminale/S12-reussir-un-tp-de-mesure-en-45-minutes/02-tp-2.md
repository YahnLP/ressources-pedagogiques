## ⏱️ Séquençage optimal 45 min

```
0-3 min   → Lire TOUT le sujet · repérer les pièges
3-11 min  → Résistances (CIRCUIT ÉTEINT) + diode
11-21 min → Tensions + calculs (I_LED, Vf) · rallumer
21-29 min → Mesures spéciales (DHT22 × 5, oscillo)
29-43 min → Calculs (métrologie, thermique) + PV complet
43-45 min → Vérification · signer · rendre

⚠️ Si bloqué > 3 min : écrire "non mesuré" et avancer
```

---

## 🧠 8 Réflexes automatiques

```
① Résistance → ÉTEINDRE avant (toujours !)
② Calculer les plages AVANT de comparer
③ Unité à chaque case (Ω, V, mA, °C)
④ Formules métrologie : biais/σ/u/U
⑤ |biais|+U ≤ spécif. → écrire les chiffres
⑥ Vérifier cohérence décision / non-conformités
⑦ Décision PV = 1 des 3 options (conf./sous rés./KO)
⑧ SIGNER avant de rendre (toujours !)
```

## 🖊️ Formulations types

```
CONFORME :
"X = ___ ∈ [___ ; ___] → CONFORME."

NON CONFORME :
"X = ___ ∉ [___ ; ___] → NON CONFORME.
 Impact : ___ . Recommandation : ___."

MÉTROLOGIE :
"|e̅|+U = ___+___ = ___ ≤ 0,5°C → CONFORME."
ou "= ___ > 0,5°C → NON CONFORME."

THERMIQUE :
"Pdiss=___W · Tj=___°C · Marge=___°C → OK / KO."
```

```

⑤ SIGNER
```

---

## 🚨 5 erreurs mortelles

```
❌ Résistance sous tension → valeur fausse
❌ PV non signé → −5 pts
❌ Conformité sans calculer la plage
❌ Conclusion incohérente avec mesures
❌ Formulation vague ("c'est pas bon")
```

---

## 📐 Formules éclair

```
Plage ±5%  : [Nom×0,95 ; Nom×1,05]
Plage ±1%  : [Nom×0,99 ; Nom×1,01]
I_LED      = (Vcc − Vf) / R
Pdiss      = (Vin − Vout) × Iout
Tj         = Tamb + Pdiss × Rθja  (Tj max = 105°C)
|biais|+U  = critère conformité métrologie
```
