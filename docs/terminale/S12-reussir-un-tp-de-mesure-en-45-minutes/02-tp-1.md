# 📘 COURS MÉTHODE — S12 · 3ᵉ ANNÉE · E2
## Réussir un TP de Mesure en 45 Minutes : Rapidité sans Sacrifier la Précision

---

> **Durée** : 20 minutes · **Support** : fiche cours + démonstration enseignant

---

## 🔑 Le paradoxe de la rapidité

```
❌ ERREUR FRÉQUENTE : "Pour aller vite, je fais moins bien."

✓ RÉALITÉ : La rapidité vient de la méthode, pas de la précipitation.
  Un apprenant qui connaît exactement l'ordre des actions va 2× plus vite
  qu'un apprenant qui cherche quoi faire — avec la même qualité.

LES 3 VOLEURS DE TEMPS dans un TP de mesure :
  1. Lire le sujet APRÈS avoir commencé → refaire ou corriger
  2. Changer de configuration instrument à mi-chemin → manipulation perdue
  3. Calculer les formules à la main sans mémo → lenteur et erreurs
```

## 1️⃣ — Le séquençage optimal (45 minutes)

### Minutage type recommandé

```
PHASE 0 — Lecture (3 min) :
  → Lire TOUT le sujet avant de toucher un instrument
  → Identifier : combien de mesures ? Quelles formules ? Le PV est-il long ?
  → Décider l'ordre (pas forcément l'ordre du sujet !)

PHASE 1 — Mesures résistances HORS TENSION (8 min) :
  → Éteindre le circuit EN PREMIER
  → Mesurer toutes les résistances d'un coup (pas alterner éteint/allumé)
  → Calculer immédiatement les plages de tolérance et noter la conformité

PHASE 2 — Mesures sous tension (10 min) :
  → Rallumer le circuit
  → Mesures de tensions (pas besoin de modifier les branchements)
  → Calculs dérivés (courants, puissances) sur place

PHASE 3 — Mesures spéciales (8 min) :
  → Oscilloscope si demandé (fréquence, amplitude)
  → Lecture Serial monitor Arduino
  → Mesures DHT22 (5 relevés minimum, attendre 2s entre chaque)

PHASE 4 — Calculs et PV (16 min) :
  → Métrologie si demandée (biais, σ, U)
  → Bilan thermique si demandé (Pdiss, Tj)
  → Remplir le PV EN DERNIER (mais ne pas dépasser 12 min)
  → Signer avant de rendre

5 min de MARGE → pour les imprévus et la vérification finale
```

## 2️⃣ — Les 8 réflexes automatiques

```
RÉFLEXE 1 — Avant TOUTE mesure de résistance :
  "Est-ce que le circuit est ÉTEINT ?"
  Action : déconnecter l'USB avant de mesurer

RÉFLEXE 2 — Avant de noter une valeur :
  "Quelle est la plage de tolérance ?"
  Action : calculer [nominale × 0,95 ; nominale × 1,05] dès que la valeur nominale est connue

RÉFLEXE 3 — Après avoir rempli une case :
  "Ai-je l'unité ?"
  Action : vérifier Ω/V/mA/°C à chaque case

RÉFLEXE 4 — Avant les calculs métrologie :
  "Ai-je les 4 formules ? biais, σ, u, U"
  Action : les écrire sur le brouillon AVANT de calculer

RÉFLEXE 5 — Après les calculs :
  "La décision de conformité est-elle justifiée par les chiffres ?"
  Action : toujours écrire |biais| + U = ______ ≤ spécification ou non

RÉFLEXE 6 — Avant le PV :
  "Ai-je toutes les valeurs pour remplir le tableau de synthèse ?"
  Action : relire rapidement les mesures effectuées

RÉFLEXE 7 — Avant de signer le PV :
  "Est-ce que la décision (conforme / sous réserve / refusé) est cohérente ?"
  Action : relire les non-conformités identifiées

RÉFLEXE 8 — En dernier, avant de rendre :
  "Le PV est-il signé ?"
  Action : signer MÊME si incomplet — 5 points automatiquement perdus sinon
```

## 3️⃣ — La formulation professionnelle

### Ce qui distingue un PV de qualité

```
FORMULATION INSUFFISANTE :
  "La résistance n'est pas bonne."
  "Le capteur dévie un peu."
  "Ça semble conforme."

FORMULATION PROFESSIONNELLE :
  "R_LED mesurée = 330 Ω. Plage acceptable pour 220 Ω ±5% = [209 ; 231] Ω.
   330 Ω ∉ [209 ; 231] Ω → NON CONFORME.
   Impact : I_LED = (3,3 − 2,0) / 330 = 3,9 mA < 10 mA recommandé.
   Recommandation : remplacer R_LED par 220 Ω."

FORMULATION PROFESSIONNELLE (métrologie) :
  "Biais = +0,21°C. U = 0,22°C.
   Critère : |biais| + U = 0,43°C ≤ 0,5°C (spécification DHT22).
   Décision : CONFORME. Note : valeur proche de la limite, surveillance recommandée."
```

### Phrases types à mémoriser

```
Pour une non-conformité :
  "X mesuré = ___. Nominal = ___ ±___%. Plage = [___ ; ___].
   X ∉ [___ ; ___] → NON CONFORME. Impact : ___. Recommandation : ___."

Pour une conformité :
  "X mesuré = ___. Plage = [___ ; ___]. X ∈ [___ ; ___] → CONFORME."

Pour la conclusion métrologie :
  "|biais| + U = ___ + ___ = ___ °C ≤ ___ °C (spécification) → CONFORME."
  ou "= ___ > ___ → NON CONFORME."

Pour la conclusion PV :
  "La station est CONFORME / NON CONFORME / CONFORME SOUS RÉSERVE.
   [Non-conformités : lister]. [Recommandations : lister]."
```

## 4️⃣ — Gestion des blocages

```
SITUATION : "Je suis bloqué sur une mesure."
SOLUTION   : Écrire "Non mesuré — instrument non disponible" ou "Mesure impossible
             dans les conditions actuelles" et CONTINUER.
             Ne jamais rester bloqué > 3 minutes sur un point.

SITUATION : "Je n'arrive pas à calculer le σ."
SOLUTION   : Écrire "Calcul en cours" ou donner le résultat approximatif.
             Un tableau incomplet = quelques points perdus.
             Un tableau vide = tous les points perdus.

SITUATION : "Il reste 5 minutes et le PV est vide."
SOLUTION   : Remplir a minima : date, opérateur, décision globale, signer.
             Un PV partiel signé > un PV vide non signé.

SITUATION : "J'ai fini en 35 minutes."
SOLUTION   : Vérifier dans cet ordre :
             1. PV signé ? 2. Toutes les unités présentes ? 3. Conformités justifiées ?
             4. Recommandations rédigées ? 5. Formulations professionnelles ?
```

## 📌 Les 5 erreurs qui font perdre le plus de points

```
ERREUR 1 — PV non signé : −5 pts automatiquement
ERREUR 2 — Résistance mesurée sous tension : valeur fausse → cascade d'erreurs
ERREUR 3 — Conformité décidée sans calculer la plage : "ça semble dans les normes"
ERREUR 4 — Conclusion PV incohérente avec les non-conformités trouvées
ERREUR 5 — Formulations vagues : "c'est pas bon", "ça dévie un peu"
```
