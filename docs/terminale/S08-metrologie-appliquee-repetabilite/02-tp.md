### Calcul de la répétabilité opérateur A

```
Moyenne x̄_A = Σ(T°_A) / 10 = _______ °C

Écart-type σ_A = √(Σei² / (n−1)) = √(_______ / 9) = √_______ = _______ °C

Étendue R_A = max − min = _______ − _______ = _______ °C
```


??? tip "💡 Aides pour la partie 1"
    - **Avant de mesurer** : laisse le capteur **se stabiliser** quelques minutes, ne souffle pas dessus et attends **au moins 2 secondes** entre deux lectures (contrainte du DHT22).
    - **Ordre de calcul** : moyenne → écarts $e_i$ → carrés → somme → division par $n-1$ → racine. **Contrôle** : la somme des écarts doit être **proche de zéro** (aux arrondis près) ; sinon, la moyenne est fausse.
    - **Ordres de grandeur** : pour un DHT22 en air calme, l'écart-type est de l'ordre de **0,05 à 0,3 °C** et l'étendue (max − min) de **quelques dixièmes de degré**. Une valeur de **plusieurs degrés** signale une **erreur de lecture** ou une perturbation.

## 🟠 PARTIE 3 — Gauge R&R complet (20 min)

### Étape 1 — Répétabilité (EV)

$$\sigma _EV = \dfrac{\sigma _A + \sigma _B}{2} = \dfrac{\underline{\hspace{2.5em}} + \underline{\hspace{2.5em}}}{2} = \underline{\hspace{2.5em}} °C$$

Intervalle de répétabilité à 99% : 5,15 × $σ_{\mathrm{EV}}$ = \_\_\_\_\_\_\_ °C  
Interprétation : si le MÊME opérateur refait une mesure, il peut observer jusqu'à  
\_\_\_\_\_\_\_ °C de variation, rien qu'à cause du bruit d'équipement.  

### Étape 2 — Reproductibilité (AV)

```
Différence des moyennes :
AV_brut = |x̄_A − x̄_B| = |_______ − _______| = _______ °C

Si AV_brut > 0 :
  σ_AV ≈ AV_brut / √n = _______ / √10 = _______ / 3,162 = _______ °C
  (approximation acceptable pour p=1 pièce)

Interprétation : les deux opérateurs diffèrent en moyenne de _______ °C.
```

### Étape 3 — GRR total

$$\sigma _GRR = \sqrt{\sigma _EV^2 + \sigma _AV^2}$$

$$= \sqrt{\underline{\hspace{2.5em}} ^2 + \underline{\hspace{2.5em}} ^2}$$

$$= \sqrt{\underline{\hspace{2.5em}} + \underline{\hspace{2.5em}}}$$

= √\_\_\_\_\_\_\_  

$$= \underline{\hspace{2.5em}} °C$$

### Étape 4 — %GRR

Tolérance du procédé = ±2°C → Tolérance totale = 4°C  

%GRR = (5,15 × $σ_{\mathrm{GRR}}$ / Tolérance) × 100  

$$= (5{,}15 \times \underline{\hspace{2.5em}} / 4) \times 100$$

$$= \underline{\hspace{2.5em}} %$$

DÉCISION :  
☐ %GRR < 10%       → EXCELLENT : DHT22 validé ✓✓  
☐ 10% ≤ %GRR ≤ 30% → ACCEPTABLE : DHT22 utilisable avec précautions ✓  
☐ %GRR > 30%       → INACCEPTABLE : DHT22 insuffisant pour cette application ✗  

### Étape 5 — NDC (Number of Distinct Categories)

```
Pour calculer NDC, on a besoin de σ_pièce (variabilité des pièces).
En l'absence de données pièces, on utilise une approximation :
  Si %GRR est correct, NDC ≥ 5 est généralement satisfait pour %GRR < 20%.

Conclusion NDC (estimation) : NDC ☐ probablement ≥ 5 ☐ probablement < 5
```


??? tip "💡 Aides pour la partie 3"
    - **Répétabilité (EV)** : c'est la dispersion due à **l'instrument** quand **le même opérateur** répète la mesure.
    - **Reproductibilité (AV)** : c'est la dispersion due au **changement d'opérateur**. Si les moyennes sont **très proches**, elle est **petite**, voire **nulle**.
    - **GRR** : on **compose** les deux en **racine carrée de la somme des carrés** (comme des incertitudes).
    - **%GRR** : compare l'intervalle $5{,}15\,\sigma_{GRR}$ à la **tolérance totale** (4 °C ici, soit ±2 °C). Un %GRR **de quelques pour cent à une quinzaine** est **courant** pour un DHT22 en bon état ; **au-dessus de 30 %**, l'instrument est **inadapté**.
    - **Décision** : coche **une seule case** et **justifie avec ton chiffre**.
    - **NDC** : c'est une **estimation** ; justifie-la par ton %GRR.

## 🔵 PARTIE 4 — Limite de détection du DHT22 (10 min)

### Calcul de la limite de détection

Le $σ_{\mathrm{EV}}$ calculé représente le bruit propre du capteur (répétabilité).  
On l'utilisera comme $σ_{\mathrm{bruit}}$ pour calculer LD.  

$$\sigma _bruit = \sigma _EV = \underline{\hspace{2.5em}} °C$$

LDD (Limite de Décision) = 1,65 × $σ_{\mathrm{bruit}}$ = 1,65 × \_\_\_\_\_\_\_ = \_\_\_\_\_\_\_ °C  

LD (Limite de Détection) = 3,3 × $σ_{\mathrm{bruit}}$ = 3,3 × \_\_\_\_\_\_\_ = \_\_\_\_\_\_\_ °C  

Règle pratique 3-sigma : LD ≈ 3 × \_\_\_\_\_\_\_ = \_\_\_\_\_\_\_ °C  

### Évaluation de l'aptitude à la détection

```
L'ingénieur veut détecter des variations de ±1°C (variation minimale d'intérêt).

La LD calculée est _______ °C.

LD < 1°C → Le DHT22 peut détecter les variations de ±1°C : ☐ Oui ☐ Non

Si Non : quelle amplitude minimale peut-il détecter de façon fiable ?
  Amplitude minimale détectable = LD = _______ °C

Conséquence pratique : si la LD est > 1°C, certaines variations importantes
  resteront indétectables → risque de passer à côté d'une dérive.
```


??? tip "💡 Aides pour la partie 4"
    - La **limite de détection** est **proportionnelle** au bruit : plus l'instrument est bruité, **plus la plus petite variation détectable est grande**.
    - Tes trois valeurs (1,65 σ, 3,3 σ, 3 σ) doivent être **du même ordre de grandeur** ; la règle des 3 sigma est une **approximation** de la deuxième.
    - Pour répondre à « peut-il détecter ±1 °C ? », compare **LD** à **1 °C** : si LD est **nettement plus petite**, la réponse est oui avec marge ; si elle est **proche**, dis que la marge est **faible**.
