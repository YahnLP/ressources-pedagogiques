## ⚡ Procédures mesure

```
RÉSISTANCES :
  ① Circuit ÉTEINT (déconnecter USB)
  ② Sélectionner Ω sur multimètre
  ③ Mesurer 2 fois (repositionner les sondes)
  ④ Calculer l'écart en % vs nominal
  ⑤ Comparer à la tolérance (±5% ou ±10%)

TENSIONS :
  ① Circuit SOUS TENSION
  ② Voltmètre en PARALLÈLE
  ③ Rouge → + · Noir → GND

DIODE :
  ① Mode test diode (symbole ─|►─)
  ② Sens passant → 0,5-0,7V ✓
  ③ Sens bloqué → OL ✓
```

## 📏 Formules à mémoriser

$R_{\mathrm{conforme}}$ : |R_mesurée − $R_{\mathrm{nominale}}$| / $R_{\mathrm{nominale}}$ × 100 ≤ tolérance%  

$$I_{\mathrm{LED}} = \dfrac{V_{cc} - V_{\mathrm{F}}}{R_{\mathrm{LED}}}$$

Pdiss = (Vin − Vout) × Iout  

Tj = Tamb + Pdiss × Rθja  
Tj_max exploitable = 105°C (125−20)  

Métrologie :  
Biais = Σei/n · σ=$\sqrt{Σei²/(n−1}$) · u=σ/$\sqrt{n}$ · U=2u  
Conformité : |biais|+U ≤ spécification

## 🚨 Pièges mortels

```
❌ Mesurer résistance sous tension → valeur fausse → 0pts
❌ PV non signé → -5pts automatique
❌ Partie D vierge → 0/20 sur C5
❌ Conclusions sans chiffres ("c'est pas bon")
❌ Tolérance calculée APRÈS la mesure (l'inverse !)
❌ Unités oubliées (Ω, V, mA, °C)
```

```

NON CONFORME :
"R_LED = 330 Ω · Nominal 220Ω ±5% = [209;231]Ω
 330 Ω ∉ [209;231] → NON CONFORME
```
