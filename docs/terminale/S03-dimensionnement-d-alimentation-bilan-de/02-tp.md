## 🟢 EXERCICE 1 — Bilan de puissance CLIMASENS (20 min)

> Établis le bilan de puissance complet de la station CLIMASENS.

### Données

```
Composants de la station CLIMASENS :
  ESP32 (actif WiFi)   : 150 mA @ 3,3V (valeur mesurée)
  ESP32 (veille légère): 10 mA  @ 3,3V  (entre deux mesures)
  DHT22                : 1,5 mA @ 3,3V  (en lecture, sinon < 0,1 mA)
  MQ-2                 : 150 mA @ 5,0V  (chauffage constant)
  LED statut           : 10 mA  @ 3,3V  (clignotement 1s ON / 4s OFF)

Cycle de fonctionnement :
  → Toutes les 30 secondes : 5s de mesure + envoi WiFi (ESP32 actif WiFi)
  → Les 25 secondes restantes : ESP32 en veille légère
  → MQ-2 : chauffage en permanence
  → LED : 1s allumée / 4s éteinte en permanence
```

**Q1.a** — Complète le tableau de bilan :

| Composant | Tension (V) | $I_{\mathrm{pic}}$ (mA) | $I_{\mathrm{moy}}$ (mA) | $P_{\mathrm{moy}}$ (mW) |
|---|---|---|---|---|
| ESP32 actif WiFi | 3,3 | 150 | *voir Q1.b* | |
| ESP32 veille | 3,3 | 10 | *voir Q1.b* | |
| DHT22 | 3,3 | 1,5 | 0,25 | |
| MQ-2 | 5,0 | 150 | 150 | |
| LED (1s ON / 4s OFF) | 3,3 | 10 | *voir Q1.c* | |
| **TOTAL 3,3V** | — | | | |
| **TOTAL 5V** | — | 150 | 150 | 750 |

**Q1.b** — Calcule le courant MOYEN de l'ESP32 sur un cycle de 30s :

$$
\begin{aligned}
I_{\mathrm{moy}} ESP32 &= \dfrac{I_{\mathrm{actif}} \times t_{\mathrm{actif}} + I_{\mathrm{veille}} \times t_{\mathrm{veille}}}{t_{\mathrm{total}}} \\
&= \dfrac{150 \times \underline{\hspace{2.5em}} + 10 \times \underline{\hspace{2.5em}}}{30} \\
&= \dfrac{\underline{\hspace{2.5em}} + \underline{\hspace{2.5em}}}{30} \\
&= \underline{\hspace{2.5em}} mA
\end{aligned}
$$

**Q1.c** — Calcule le courant MOYEN de la LED (cycle 1s ON / 4s OFF) :

$$
\begin{aligned}
I_{\mathrm{moy}} LED &= I_{\mathrm{LED}} \times (\dfrac{t_{\mathrm{ON}}}{t_{\mathrm{total}}}) \\
&= 10 \times (1 / \underline{\hspace{2.5em}}) = \underline{\hspace{2.5em}} mA
\end{aligned}
$$

**Q1.d** — Si l'alimentation 3,3V est fournie par un LDO depuis une source 5V,
quel est le courant total consommé côté 5V ?

I_total_source_5V ≈ I_total_3,3V (les courants se conservent en régulateur linéaire, ≈ Iin ≈ Iout)  

$\displaystyle I_{\mathrm{total\_source\_5}}\,\mathrm{V} = I_{3}{,}3\,\mathrm{V} + I_{\mathrm{MQ2}} = \underline{\hspace{2.5em}} + 150 = \underline{\hspace{2.5em}} mA$

Courant de pointe (lors de l'émission WiFi) :  

$\displaystyle I_{\mathrm{pic\_total}} = I_{\mathrm{pic\_ESP32}} + I_{\mathrm{DHT22}} + I_{\mathrm{LED}} + I_{\mathrm{MQ2}} = \underline{\hspace{2.5em}} mA$

**Q1.e** — Si on utilise une batterie 5V de 2000 mAh, quelle est l'autonomie théorique ?

```
t = 2000 mAh / _______ mA = _______ heures
t_réelle ≈ _______ × 0,80 = _______ heures
```

??? success "Réponses"
    **Q1.a et Q1.b** : $I_{moy}$ ESP32 = (150 × 5 + 10 × 25) / 30 = (750 + 250) / 30 ≈ 33,3 mA, soit 25 mA (actif) + 8,3 mA (veille).
    
    | Composant | $I_{moy}$ (mA) | $P_{moy}$ (mW) |
    |---|---|---|
    | ESP32 actif WiFi | 25 | 82,5 |
    | ESP32 veille | 8,3 | 27,5 |
    | DHT22 | 0,25 | 0,8 |
    | LED (1 s ON / 4 s OFF) | 2 | 6,6 |
    | **TOTAL 3,3 V** | 35,6 (pic : 161,5) | 117 |
    
    **Q1.c** : $I_{moy}$ LED = 10 × (1 / 5) = 2 mA  
    **Q1.d** : côté 5 V : 35,6 + 150 ≈ 185,6 mA ; courant de pointe : 150 + 1,5 + 10 + 150 = 311,5 mA  
    **Q1.e** : t = 2 000 / 185,6 ≈ 10,8 h ; $t_{réelle}$ ≈ 10,8 × 0,80 ≈ 8,6 h

## 🟡 EXERCICE 2 — Calcul thermique du régulateur (20 min)

> Le régulateur LDO AMS1117-3.3 alimente l'ESP32 et les capteurs depuis le 5V.

### Données AMS1117-3.3 (extrait datasheet)

```
Boîtier : SOT-223 ou TO-252
Vout : 3,3V fixe
Iout max : 1A
Tj max : 125°C
Rθjc : 5°C/W (jonction → boîtier)
Rθja : 44°C/W (jonction → air, sans radiateur, sur PCB standard)
```

**Q2.a** — Calcule la puissance dissipée par le LDO avec Vin=5V, Iout = I_total_3,3V calculé en Q1.d :

Pdiss = (Vin − Vout) × Iout  

$\displaystyle = (5{,}0 - 3{,}3) \times \underline{\hspace{2.5em}}$

$\displaystyle = 1{,}7 \times \underline{\hspace{2.5em}}$

$\displaystyle = \underline{\hspace{2.5em}} W$

**Q2.b** — Calcule la température de jonction sans radiateur, Tamb = 25°C :

Tj = Tamb + Pdiss × Rθja  

$\displaystyle = 25 + \underline{\hspace{2.5em}} \times 44$

$\displaystyle = 25 + \underline{\hspace{2.5em}}$

$\displaystyle = \underline{\hspace{2.5em}} °C$

**Q2.c** — La marge thermique est-elle suffisante ?

```
Tj max exploitable = 125 − 20 = 105°C (marge de sécurité 20°C)
Tj calculée        = _______ °C

☐ Tj < 105°C → Aucun radiateur nécessaire ✓
☐ Tj > 105°C → Radiateur ou réduction de courant nécessaire
```

**Q2.d** — Lors du pic de courant (I_pic_total calculé en Q1.d), la température monte-t-elle trop ?

Pdiss_pic = 1,7 × ($I_{\mathrm{pic}}$ / 1000) = 1,7 × \_\_\_\_\_\_\_ = \_\_\_\_\_\_\_ W  

$\displaystyle Tj_pic = 25 + \underline{\hspace{2.5em}} \times 44 = \underline{\hspace{2.5em}} °C$

Le LDO survit au pic ? ☐ Oui (Tj_pic < 125°C) ☐ Non → solution : \_\_\_\_\_\_\_\_\_\_\_\_\_  

**Q2.e** — En été dans un boîtier industriel, Tamb peut atteindre 60°C. Recalcule Tj :

```
Tj_été = 60 + Pdiss × 44 = 60 + _______ = _______ °C
Conforme ? ☐ Oui ☐ Non → Action requise : ___________________________________
```

??? success "Réponses"
    **Q2.a** : $P_{diss} = 1{,}7 \times 0{,}0356 \approx 0{,}060\,\mathrm{W}$  
    **Q2.b** : $T_j = 25 + 0{,}060 \times 44 \approx 27{,}7\,°\mathrm{C}$  
    **Q2.c** : $T_j$ ≈ 27,7 °C < 105 °C : aucun radiateur nécessaire.  
    **Q2.d** : avec $I_{pic}$ = 311,5 mA (valeur de Q1.d) : $P_{diss}$ = 1,7 × 0,3115 ≈ 0,53 W ; $T_j$ = 25 + 0,53 × 44 ≈ 48 °C < 125 °C : le LDO survit au pic. (Le MQ-2 est alimenté directement en 5 V : seul 161,5 mA traverse réellement le LDO, soit 0,27 W et environ 37 °C.)  
    **Q2.e** : $T_j$ = 60 + 0,060 × 44 ≈ 62,7 °C < 105 °C : conforme, aucune action requise.

??? success "Réponses"

    **Application C** : Linéaire (LM7815 / LM7915). Il ne commute pas : pas de bruit de découpage ni d'émissions CEM sur le signal analogique, la tension reste très propre.
