# PARTIE 2 — PREUVES PAR COMPÉTENCE

## Guide de sélection des preuves

> **Règle d'or :** 1 preuve = 1 production réelle qui démontre la compétence à quelqu'un qui ne vous connaît pas.

### Ce qui compte comme preuve

| **Type** | **Exemples** | **Qualité** |
|---|---|---|
| Fichier produit | .kicad_sch ERC=0, code .ino fonctionnel, Gerber | ⭐⭐⭐ |
| Document rédigé | PV de mesure, fiche MES, DAT, BOM | ⭐⭐⭐ |
| Capture d'écran annotée | Dashboard CloudWatch, analyseur logique décodé, ERC 0 erreur | ⭐⭐ |
| Photo de réalisation | Boîtier imprimé, carte câblée, maquette test | ⭐⭐ |
| Résultat de test | Plan de tests signé avec résultats réels | ⭐⭐ |

### Ce qui NE compte pas comme preuve

```
❌ Copie d'une fiche de cours
❌ "J'ai compris le principe de..."
❌ Exercice non terminé ou non corrigé
❌ Copier-coller d'un corrigé de TP
```
